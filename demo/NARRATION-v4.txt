DappGo existed before this hackathon. This verifier, its site and every piece of evidence were built between October 27 and November 4.

A finance post goes viral. Thousands repost it. Is it right? This one has a real number — and the wrong period. Numbers like this move money, and wrong numbers lose it.

And it's not just text. Screenshots, PDFs, podcasts, videos — numbers everywhere. How do you check all of them?

Asking a model directly gets one in five right. Give the same model SEC evidence, and let a program decide: nine in ten — on held-out claims, 240 of 266.

Here's how. Meta's Muse Spark reads the post, extracts each claim and chooses which SEC lookup to run. Python does the arithmetic and returns the verdict. The model proposes; the program decides.

Live, on the site. Paste the post. Muse Spark calls the SEC tools — you can see each call. Apple's annual revenue was $416 billion; the quarter was $102.5 billion. Contradicted, with the filing. One cent, six seconds. And here is the corrected draft.

The same checks run in batch from the command line — text, screenshots through Muse OCR, audio through Muse Voice Transcribe. Measured timing will come from the saved runs.

Ninety point two percent on held-out claims. It wrongly says 'supported' once in 139. Two cents and ten seconds a claim. On real posts, coverage is reported separately from accuracy.
