# Site image prompts

These three illustrations were generated on 2026-10-28 with the built-in `image_gen.imagegen` tool. The exact prompts are in [`hero.md`](hero.md), [`model-program.md`](model-program.md), and [`evidence.md`](evidence.md). The final optimized PNGs live in `docs/site/img/` and are kept below 400 KB.

To regenerate or make a variant:

1. Use the built-in image-generation tool with the exact prompt from the relevant file.
2. Keep the paper-and-ink palette and the constraints against readable text, numbers, logos, brands, faces, hands, screens, and watermarks.
3. Save the selected output into `docs/site/img/`, resize to no more than 1600 px wide, and optimize it to no more than 400 KB.
4. Update the output dimensions, file size, date, and prompt file if the new asset replaces an existing one.

Images are illustrations only. The website's claims and numbers come from `docs/explorer/data.json` and the generated `docs/site/data/site.json` snapshot.
