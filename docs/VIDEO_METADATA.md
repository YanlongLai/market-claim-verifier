## YouTube title

Market Claim Verifier: SEC-Checked Finance Posts with Muse Spark

## YouTube description

Paste a finance post. Market Claim Verifier extracts financial assertions, selects SEC tools with Meta Muse Spark, and lets Python bind evidence and decide `supported`, `contradicted`, or `insufficient_evidence`. It returns a corrected draft with citations.

Recorded headline: Baseten's corrected-gold held-out text split reached 90.2% (240/266); false support was 1/139 among non-supported claims. The benchmark rounded to ~$0.02 per claim. The live-text planning band is 6–25 s per Baseten check by input size; it is guidance, not an SLA.

The site includes saved examples with no password, live checks using the judge password (the team name), public history, and three providers. The CLI supports text, images, native-text PDFs, audio, and video; media supplies claim text, not financial evidence.

Disclosure: Nothing in this repository pre-existed the hackathon.
