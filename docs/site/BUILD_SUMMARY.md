# Site build summary

Created for the `site/landing` branch:

- `index.html`, `styles.css`, and `script.js` — responsive, accessible static landing page with light/dark color schemes, native HTML workflow diagram, data-driven SVG accuracy chart, results table, provider paths, evidence tiers, post checker, and run instructions.
- `data/site.json` — generated by `docs/scripts/build_site.py` from `docs/explorer/data.json` and the eval summary. It contains only the page’s selected evaluation numbers and three evidence examples.
- `img/hero.png`, `img/model-program.png`, and `img/evidence.png` — optimized PNG illustrations, each no more than 1600 px wide and under 400 KB.
- `docs/prompts/site/hero.md`, `model-program.md`, `evidence.md`, and `README.md` — exact prompts, tool/date/output records, and regeneration notes.

Image prompts used: `hero.md` for the claim-to-filings hero, `model-program.md` for the loose model marks becoming a precise program decision, and `evidence.md` for the filing archive/provenance still life. All were generated with the built-in `image_gen.imagegen` tool on 2026-10-28.

Numbers: every displayed evaluation number is sourced from the checked-in explorer data or summary. No requested number was left unsourced.

Checks completed: `python3 docs/scripts/build_site.py`, JSON validation, JavaScript syntax validation, local-reference validation, and taste-skill lint (`0 FAIL, 0 WARN`). A local `python3 -m http.server -d docs/site` was started. The taste-skill headless inspector could not launch Chrome in this environment, and the connected Chrome surface declined the local-origin permission, so visual 375 px / 1280 px screenshot checks remain an environment limitation rather than a claimed pass.
