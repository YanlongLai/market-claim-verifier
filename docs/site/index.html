How it works

A short path from a social post to a source you can open.

  1. Find every money claim

    The AI uses Meta's Muse Spark models to find each number, period, and comparison in the post.

  2. Open the official filing

    It looks up the company's SEC filing for the same company, number, and time period.

  3. Let code decide

    Code, not the AI, compares the numbers and gives the final True, False, or Can't check verdict.

Does it work?

Adding an SEC lookup and simple checks raises accuracy for all three ways to run Muse.

Tested on the evaluation claims with known answers.

For researchers

    Why you can trust it

    The source and the rules stay visible.

    • Every answer links to the filing.
    • The AI cannot change the numbers it quotes. If the quote changes, it is rejected.
    • We publish our own mistakes in BUILD_LOG.md.
