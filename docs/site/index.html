Claims hide in plain sight.

A sentence can be numerically close and still be wrong: the period can be fiscal, the comparator can be “at least,” or a record claim can quietly fail its history check. These are three claims from the evaluation where a tool-free answer missed the point.

Examples are drawn from the frozen v2 evaluation snapshot. The agent path shown is Baseten; the evidence values are cached SEC XBRL facts.

The program has the last word.

The model is useful for decomposition, tool selection, and explanation. The program re-parses the claim’s own words and refuses to let a polished draft overrule a mismatch.

Model proposes Program decides
  1. Model

    Split the claim

    Turn one sentence into atomic assertions: value, period, change, record.

  2. Model

    Call SEC tools

    Use lookup, history, period, and change tools against cached EDGAR facts.

  3. Program

    Parse the words

    Read the stated number, precision, unit, direction, and comparator again.

  4. Program

    Check the trail

    Validate evidence IDs, fiscal and calendar readings, provenance, and strength.

  5. Program

    Return the verdict

    Choose supported, contradicted, or insufficient evidence. The program wins a disagreement.

Every verdict leaves a trail.

Evidence strength tells a reader what kind of filing path supports the claim. The verifier keeps the source rows, filing forms, periods, accessions, and whether a value was derived.

L1 · audited 10-KExact value reported in an annual filing.
L2 · reviewed 10-QExact value reported in a quarterly filing.
L3 · derivedProgram calculation such as annual minus nine-month YTD, with components retained.

Honesty is a feature.

The cached data is checked too. Oracle’s 10-Ks filed in 2020–2022 contain full-year revenue tagged on fourth-quarter periods for several fiscal years; the verifier excludes those rows and derives the real March–May 2018 quarter as $11.0B.

When the gold answer moved.

The eval surfaced two corrections: Amazon’s 12-month 10-Q figure was a trailing-twelve-month value, not a fiscal year; Apple’s 52/53-week quarter ending 2023-07-01 belongs to calendar Q2, not Q3. The frozen claims stay unchanged; the reasons are recorded.

Check a whole post.

Point the CLI at a draft instead of copying sentences one by one. The post path extracts claims, rejects any quote that is not an exact span or that changes a number, skips forecasts and opinions, then verifies the rest.
