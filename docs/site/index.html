    How it works

    A short path from a social post to a source you can open.

    1. Find the claim

      The AI uses Meta's Muse Spark models to find each number, period, and comparison in the post.

    2. Open the filing

      It looks up the company's SEC filing for the same company, number, and time period.

    3. Code decides

      Code, not the AI, compares the numbers and gives the final True, False, or Can't check verdict.
