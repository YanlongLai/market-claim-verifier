# Acceptance checklist (both reviewers; PASS/FAIL with frame evidence)

1. Product name + UI visible within 3 s.
2. Phone-readable: meaningful text ≥ 56 px, numbers ≥ 96 px at 1080p; 64 px safe margin; contrast ≥ 4.5:1.
3. Subtitles on every spoken line (burned in + .srt), ≤ 2 lines × 42 chars; bottom 200 px free of key content.
4. One narrator voice in all scenes (voice-similarity check ≥ 0.85).
5. Picture matches narration: what is named is on screen when it is said.
6. Every number matches the data source and is consistent across shots; no rounding-dependent "gotchas".
7. No clipping, overlap, escaped HTML (e.g. `&#39;`), typos, inconsistent fonts or colours.
8. Length within limit; loudness −14 LUFS ±1 LU, true peak ≤ −1 dBTP.
9. Required statements present (e.g. built during the event, model credits); CTA URL and QR work.
