## 能證明什麼

這是一個真實場景、兩種編碼、三家文字查核路線的六次操作測試。三家全部使用 Meta ASR／OCR，且每次重新轉錄，不能當成三家原生聽力排名，也不能和先前凍結前處理的公平 benchmark 混合。畫面是真實財務投影片，沒有覆蓋快速切鏡、人物身分或多人打斷等情境。

官方字幕提供 11 個數值出現位置作為轉錄參考。報告只量測這些數值 token 是否出現，沒有把它稱為 WER、財務準確率或完整主張覆蓋率；相同數字的不同語意、期間及口徑仍須另外檢查。字幕不是獨立人工 gold。每個抽取視窗／channel 最多四個提案，因此不能預期十一個口述數值都獲得查核。

## 真實資料暴露的問題

1. **聲音缺明確期間。** CFO 在片段中說「this quarter」。來源網頁雖然有 FY2027 Q1，現有音訊流程不會默默把網頁日期加到原文。多筆數字因此以 `missing_period` 保守拒答；聽對數字不代表已有足夠財務查核上下文。
2. **影片有期間，但表格引用仍有落差。** 抽樣畫面可讀到 FY27 Q1／FY26 Q1。已保存的 Meta 結果中，抽取提案把表頭的兩位年份帶進敘述，但引用只有資料列；篩選器把 27／26 視為引用之外新增的數字而拒絕。不能為了讓它通過就忽略所有新增數字；應另外建立有來源範圍的表頭期間繫結。
3. **調整後 EPS 與 GAAP EPS 不同。** 聲音說 $4.89 並交代 OpenAI 投資調整，畫面 GAAP 列是 $4.92。不同數字不自動構成矛盾。現有產品仍各自查核聲音與畫面，沒有完成跨模態口徑對齊。
4. **真實服務也會失敗。** Meta WAV 有一筆 provider/check InternalServerError，Meta 影片第一張抽樣畫面 OCR 未完成。錯誤、原始回應和支出保留，沒有以成功重跑替換。

## 下一個開發順位

- P1：可審閱的文件／事件期間上下文。保留官方來源、取得時間、原始引用和使用者確認；明確區分「來源 metadata」與「聲音真的說了什麼」，遇到衝突仍拒答。
- P1：財報表頭的 FY27／FY2027 及季度解析，保留表頭與資料列各自的來源範圍。新增錯年度、同頁多期間及錯公司反例，不能直接放寬數字防護。
- P2：以同公司、期間、指標、GAAP／調整後、幣別及單位分組，做聲音／畫面一致性提示；保留調節表證據，不能只比較數字。
- P2：第二家公司、較長真實片段、多人與噪音場景，建立獨立標註與保留測試組，再估計真實準確率。這個已看過且已診斷的片段只能作回歸案例。

本輪結論是「真實素材已接入並留下可重用失敗證據」，不是「真實法說會可以全面自動查核」。前一輪合成素材分數保持原樣。

## 最終結果

六次轉錄都保留了參考中的 11/11 個數值 token，但本輪沒有任何主張得到 supported 或 contradicted 的程式最終判定：合計 23 筆 insufficient_evidence、28 筆引用篩選拒絕及 1 筆供應商／查核失敗。這些是同片段、跨格式／平台及重複畫面的出現次數，不是 52 個獨立事實。

Baseten WAV 的營運利益率主張另外暴露了摘要風險：模型文字摘要引用 FY2026 等期間，聲稱 50% 錯誤，但程式回傳 insufficient_evidence，子檢查為 unchecked_other_claim。不能把這段模型敘述當成驗證過的修正。原始紀錄保持可查；下一步應優先讓最終解釋只採用有效程式證據，並把模型原稿與最後判定明確分開。

新增 API 估算／保留額：Meta $0.21419575、Baseten $0.05921035、Fireworks $0.02276475，合計 $0.29617085。包含影音前處理、失敗與已記錄的重試；不是供應商帳單。加上前一輪工作，各平台仍低於原授權 $40。43 項 ingestion、股票上下文及覆蓋診斷回歸測試通過。
