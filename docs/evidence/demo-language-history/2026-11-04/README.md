# Retained legacy demo source records

The owner requested no literal Chinese in `demo/` for v5 round 2. These exact original
UTF-8 bytes preserve the earlier demo notes, source snapshots and generated data.
Each `.original.txt` file is a byte-for-byte copy made before the source cleanup.
[Manifest and hashes](manifest.json).

Executable JSON/JS/Python/YAML strings use Unicode escapes. The old v2 on-screen
label, director note and Markdown descriptions use English. Financial values, narration and
voice/cache identities are unchanged. Historical
review outcomes and numeric claims were preserved. New v5 pictures and captions are
English; these older files are retained for evidence reuse.
