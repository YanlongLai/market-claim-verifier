# Fair multimodal benchmark and stock review delivery plan

Owner authorization: 2026-10-30, up to **$40 of new spend per provider** (Meta, Baseten, Fireworks), $120 combined ceiling. These are ceilings, not spending targets. Previous runs are outside this new ledger. All preprocessing, development, native-image probes and test calls count toward the platform actually billed. No new budget is inferred for future reruns.

## Delivery order

1. Replace misleading support cells with a format integration table and a separate test-coverage/results table. A sample PNG/JPEG/WebP must never imply exclusive vendor support.
2. Freeze a reproducible controlled corpus, raw SEC snapshot references, independently calculated gold, exact files, hashes, scorer, settings-selection rule and spend policy before calls. Keep real issuer diagnostic pages separate from synthetic controls.
3. Run equally budgeted development configurations, freeze one chosen profile per platform, then run every preregistered test input. Retain incomplete attempts, errors, abstentions and all raw responses. Never report best-of test attempts.
4. Publish paired format/provider results, extraction coverage, end-to-end verdict accuracy, false-supported counts/rates, abstention, cost and latency, with sample limitations and a reusable machine index. Separate native image endpoint acceptance/reading from the application's shared Meta preprocessing pipeline.
5. Ship a single-stock multi-file review command and evidence-linked HTML/JSON summary, using the existing bounded queue. Reuse archived reports for a no-extra-credit judge example. Every file and unchecked section remains visible.
6. Follow-up: independently labeled real recordings, noisy/complex/long inputs, repeatability studies and external gold review. Do not describe the initial controlled study as a broad real-world accuracy estimate.

## Fair comparison protocol

- Same exact bytes for a given test case across all providers; same frozen SEC evidence, cutoff, tool definitions, output-token cap and scorer.
- Primary pipeline: decode/OCR/ASR once and freeze all channel text and source locations; each provider receives the **same prepared text**. This isolates text verification while including measured extraction failures in end-to-end scoring. It does not compare three vendors' audio/video encoders.
- Supplemental native-image contract/reading study: same images and verbatim-reading instructions on each provider's native API. PNG/JPEG/WebP are separate rows. No unsupported audio/video request shapes are guessed. Untested native endpoints are labeled untested, never unsupported because the repository lacks an adapter.
- Meta uses closed Muse Spark 1.3; Baseten and Fireworks use pinned Muse Spark Open models. Model/serving/profile differences are reported; this is not a pure hardware benchmark.
- Two development issuer documents, two verification-reasoning profiles (default and low), text and PNG. Choose by strict gold correctness, then fewer false-supported, then lower recorded cost. The test split is not used to choose settings or repair prompts.
- Six new issuer documents, four atomic assertions each; formats TXT, Markdown, native-text PDF, PNG, JPEG, WebP, WAV, MP3 and MP4. Each includes supported facts, a deliberately changed number and an unavailable future period. Gold is derived directly from recorded raw SEC facts, not verifier outputs. Synthetic speech is clearly labeled, not a real executive's voice.
- Format encodings are repeated measures of **24 underlying test assertions / six issuer documents**, not 216 independent truths. Publish per-format denominators and cluster-level uncertainty; no pooled confidence interval treating encodings as independent samples.
- Real Tesla pages are diagnostic candidates with no general accuracy denominator until fully annotated; do not mix them into the controlled score.
- At most two text workers per platform, balanced fixed case ordering. Cached identical prepared text may be reused only with an explicit artifact/hash reference; reused text is not counted as a new independent call or latency observation. Shared preprocessing costs are shown separately from actual per-provider charges.
- A missing/failed/unmatched gold assertion is wrong in the end-to-end denominator. Duplicate claims never inflate the score. Conflicting duplicate verdicts fail the assertion. Unmatched extractions remain visible; they are not automatically called hallucinations without a gold review.
- Latency reflects this harness, recorded concurrency and one run, not a service SLA. Costs are usage/reservation estimates, not invoices. Native media token estimates can differ; stop at $35/platform admission to leave a $5 reconciliation margin, and stop all further calls for any platform at $40. Keep failed reservations.

## Reuse contract

Commit original inputs, truth labels and source pointers, manifest, selected configuration, exact prompts/requests (media by hash reference), raw responses, normalized text, source maps, per-claim evidence/checks, reservation IDs, costs, timing and failures. Rebuild reports and summaries offline. New live reruns require a fresh directory and their own spending authority. Validation logs remain with each milestone.

## Single-stock product contract

`review-stock TICKER FILE...` runs local inputs through the existing bounded queue and writes `stock-review.json` / `stock-review.html`. `stock-summary TICKER REPORT...` reuses existing ingestion reports with zero inference cost.

The report presents source files, periods, supported/contradicted/insufficient/unchecked claims, original quotations, precise evidence and corrections. Claims for other companies are listed separately rather than relabeled. Identical statements may be grouped for reading, but every occurrence retains its file and location. An overall summary must never turn a missing section into a checked one.

The first summary is deterministic and evidence-linked. Optional AI narrative is a later, separately budgeted layer: it may explain validated facts and uncertainties with claim/evidence IDs, never supply missing financial numbers or make an unsupported buy/sell recommendation. A stock's financial direction must be expressed through verified period comparisons and explicit uncertainty, not an inferred investment rating. Uploaded issuer slides and commentary remain claims, not automatic ground truth.

## Acceptance gates

- Budget, freeze/tamper, scorer missing/duplicate/conflict, cross-ticker isolation and source-link tests pass offline.
- Plan/corpus/scorer committed before paid evaluation. Profile selection recorded before test execution.
- Raw artifact inventory and ledger totals reconcile. Every planned cell has a result or explicit failure/not-run reason.
- README English/Traditional Chinese distinguish integration, endpoint testing and measured quality.
- Full offline verification and final data/link checks pass before publication. Never change historical benchmarks to make the new study look better.

### Request-level profile clarification

The retained requests show that the two profiles change verification reasoning. The frozen short-input extractor keeps the repository default reasoning; partitioned long-input extraction uses low. Native-image calls explicitly use the selected profile. The separate stock-context product follow-up adds explicit low extraction reasoning and bounded proposals; it does not alter the frozen study.
